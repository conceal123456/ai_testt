# 古韵天工 · 3D 体素中国古典建筑群

基于 **Three.js** 打造的可交互三维体素（Voxel）风格中国古典宫殿与寺观建筑群。风格融合 Minecraft 方块美学与中国古代官式建筑典制，以严谨的中轴对称、重檐飞檐、斗拱抬梁与多进院落布局呈现。

---

## ⚡ 核心技术与性能优化

1. **极端绘制优化 (InstancedMesh)**：
   - 全场景 88,357 个体素方块全部归一合并为 **3 个 `THREE.InstancedMesh`**（实体方块、发光灯笼、微透池水）。
   - **绘制调用仅 3 次 (Draw Calls: 3)**，即使在中低配显卡或移动设备上也能轻松维持 **60 FPS** 满帧运行。
2. **光影与材质**：
   - 启用 `PCFSoftShadowMap` 真实物理软阴影与 `ACESFilmicToneMapping` 电影级色调映射。
   - 体素统一使用 `flatShading: true`，完美保留方块边缘利落的体素雕刻质感。
3. **四时晨昏光影系统**：
   - 🌅 **晨曦微露**：柔粉朝霞、薄雾缭绕、金辉初显
   - ☀️ **晴昼初霁**：正午暖阳、万里晴空、红墙黄瓦层次分明
   - 🌇 **落日熔金**：落日晚霞、金色屋顶流光溢彩、长影交错
   - 🌙 **月夜华灯**：深蓝夜空、银白月华、檐下长明灯笼透出暖黄烛光
4. **无外链纯代码音效 (Web Audio API)**：
   - 内置纯算法五声音阶合成器（宫、商、角、徵、羽），可实时弹拨古琴泛音与微风檐铃，无任何外置音频文件依赖，百分之百离线可用。

## 🚀 运行方式 (快速启动)

### 方式一：双击批处理（最简便）
1. 在项目目录中直接双击 **`启动场景.bat`**。
2. 脚本将自动启动 Vite 开发服务器并在您的默认浏览器中打开 `http://localhost:5173`。

### 方式二：命令行启动 (开发模式)
```bash
# 进入项目目录
cd C:\Users\15156\Desktop\antigravity

# 安装依赖 (如已安装可跳过)
npm install

# 启动开发服务器 (自动打开浏览器)
npm run dev
```

### 方式三：生产构建与本地预览
```bash
# 执行生产打包 (打包至 dist 目录)
npm run build

# 启动构建产物预览
npm run preview
# 或直接双击运行 预览构建版.bat
```

## 🎮 交互指南

- **打开即看全貌**：页面初始化时自动启动缓慢环绕巡航，无需操作即可全景俯瞰。
- **鼠标左键**：按住并拖动以自由旋转 360 度环视建筑群。
- **鼠标右键**：按住并拖动以平移视野。
- **滚轮缩放**：滚动滑轮放大看斗拱细节或缩小看整体格局。
- **视角按钮**：底部一键平滑飞越至【俯瞰全景】、【山门迎礼】、【庭院正殿】、【配殿回廊】、【宝塔耸翠】。
- **晨昏按钮**：随时切换晨曦、晴昼、熔金、月夜四种意境。
- **辅助开关**：支持随时切换自动巡航、禅乐微吟、网格线框透视。
