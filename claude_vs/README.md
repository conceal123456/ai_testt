# 3D 体素风格中国古典建筑群场景 (Three.js Voxel Architecture)

这是一个基于 **Three.js** 与 **Vite** 构建的高性能 3D 体素（Voxel / Minecraft 风格方块）中国古典寺观建筑群。

## 场景特色与建筑规制

1. **山门殿 (Mountain Gate)**：前庭入口，三门并列券洞、歇山顶飞檐起翘、汉白玉石狮守护
2. **晨钟楼与暮鼓楼 (Bell & Drum Towers)**：前院对称分布，双层攒尖楼阁，内置古铜大钟与红木战鼓
3. **大雄宝殿 (Grand Main Hall)**：中轴核心殿宇，三重汉白玉须弥座台基、九龙丹墀御路、重檐庑殿金黄琉璃瓦、斗拱挑檐、红柱朱门金匾
4. **东西配殿 (East & West Symmetrical Side Halls)**：对称分布于主殿前庭两侧，青绿琉璃瓦歇山顶、隔扇花窗内透暖光
5. **七层玲珑宝塔 (Seven-Tier Sacred Pagoda)**：矗立于后轴中线，七级浮屠层层收分，风铃角灯、金光万道相轮宝顶
6. **中央御道与水系园林**：青石板御道贯穿全场、九龙青铜大香炉（呼吸炭火粒子）、放生荷花池与单孔石拱桥、苍松翠柏与石灯笼

## 运行方式

### 方式一：快速启动（Windows）
直接双击根目录下的 **`双击运行.bat`** 即可启动服务并自动在默认浏览器中打开。

### 方式二：命令行启动
```bash
# 切换至项目所在盘符并进入目录
cd /d C:\Users\15156\Desktop\claude_vs

# 启动开发服务器（将自动打开 http://localhost:5173）
npm run dev
```

### 方式三：生产构建与本地预览
```bash
npm run build
npm run preview
```

## 交互指南
- **鼠标左键拖拽**：360度自由旋转全景
- **鼠标右键拖拽**：平移视角
- **鼠标滚轮**：缩放距离
- **左侧面板**：点击对应建筑名称，镜头平滑飞跃到该建筑特写
- **右侧面板**：实时切换「晨曦初照 / 金辉落日 / 清幽皓月 / 晴昼金阳」四维光影时相，开关自动漫游，或点击「鸣钟祈福」聆听古刹青铜钟声
- **性能指标**：底部状态栏实时显示当前 FPS（稳定 60 FPS）、总方块数与渲染实例数
