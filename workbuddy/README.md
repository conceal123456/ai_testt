# 太和华章 · 3D 体素中国古典建筑群 (Three.js Voxel Architecture)

这是一个基于 **Three.js** 与现代 WebGL 打造的 **3D 体素（Voxel）风格中国古典建筑群场景**。采用类似 Minecraft 的三维方块艺术语言，将中国传统古建筑营造法式的精髓（中轴对称、重檐歇山顶、飞檐翘角、出跳斗拱、汉白玉月台、七级浮屠古塔）进行了高精度的体素化转译与数字化重现。

---

## 🏛️ 场景设计与空间规制

1. **核心中轴对称布局**：
   - **金水河与汉白玉拱桥**：入口处碧波蜿蜒，三孔汉白玉石桥横跨其上，中为御桥。
   - **山门殿（前门）**：中轴首重门庭，三开间，单檐歇山顶，朱红门洞，悬挂大红宫灯。
   - **前庭院御道动线**：汉白玉与青砖交错铺设的御道直通主殿，两侧分立威严石狮、青铜大香炉、苍劲体素古柏与石灯幢。
   - **核心主殿（太和重檐大殿）**：全场核心建筑，体量最为宏伟。坐落于汉白玉须弥座月台之上，正面八根朱红金柱列阵，重檐歇山庑殿顶金瓦翻腾，四角大飞檐腾空高翘，配双龙戏珠丹陛石阶。
   - **对称东西配殿**：文殊殿与普贤殿面朝庭院中轴，单檐歇山青瓦，红墙回廊。
   - **后院七级浮屠古塔**：位于主殿后方中轴高地，七层八角密檐攒尖顶，层层叠涩出檐，顶立鎏金宝刹，直指苍穹。
   - **外围红墙灰瓦长廊**：带镂空格栅漏窗，将建筑群闭合成规整的古典宫殿院落。

2. **建筑艺术细节**：
   - **飞檐翘角算法**：采用定制的三维空间边缘翘曲与翼角提升函数，真实还原古建屋檐反宇向阳的飘逸线条。
   - **斗拱与额枋彩画**：屋檐下细致还原了青绿和玺彩画与出挑木斗结构。
   - **晨昏光影意境**：预置了【紫禁斜阳】、【晨曦破晓】、【晴空万里】、【华灯初上】四种光影色调。在夜晚模式下，所有大红灯笼与香火微光自发光点亮。

3. **极致性能架构 (InstancedMesh)**：
   - 场景包含数万个体素块，采用 `THREE.InstancedMesh` 实例化硬件批处理技术。
   - 全局仅产生约 **15 个 Draw Calls**，即使在集成显卡或移动设备上也能轻松稳定维持 **60 FPS** 满帧运行。
   - 内置面遮挡剔除（Occlusion Culling）算法，自动去除内部不可见方块，极大节约显存与计算开销。

## 🚀 运行方式

### 方式一：一键双击启动（最快最简单）
在桌面 `workbuddy` 文件夹中，**直接双击运行 `start.bat`**。
脚本会自动启动本地轻量服务并在系统默认浏览器中秒开页面！

### 方式二：Python 命令行启动
在项目根目录下打开终端，执行：
```bash
python -m http.server 8080
```
然后在浏览器中访问：`http://localhost:8080`

### 方式三：现代 Node.js / Vite 启动（可选）
如果你习惯现代前端开发流程：
```bash
npm install
npm run dev
```

## 🎮 交互控制说明

- **鼠标左键拖拽**：360° 旋转俯仰视角
- **鼠标右键拖拽**：平移视角中心
- **鼠标滚轮**：无级缩放视野
- **右上角面板**：
  - **空间视角**：支持一键平滑运镜切换【宏伟全览】、【太和主殿】、【七级宝塔】、【山门迎客】、【中轴鸟瞰】
  - **晨昏意境**：快速切换【紫禁斜阳】、【晨曦破晓】、【晴空万里】、【华灯初上】
  - **环绕巡航**：开启/暂停优雅的缓速全景自动运镜
