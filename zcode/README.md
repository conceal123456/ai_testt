# 天工营造 · 3D 体素中国古典建筑群场景 (Voxel Chinese Palace)

基于 **Three.js** 与现代 WebGL 技术打造的 3D 体素（Voxel）风格中国古典宫殿与寺观建筑群场景。画面具有 Minecraft / MagicaVoxel 风格的纯粹体素块拼接美感，兼具中国古代营造礼制与数字艺术表现力。

---

## 🏛️ 场景布局与核心建筑群（中轴对称规制）

场景内完整构建了 **7 座古典殿堂楼阁** 与完整的中轴庭院水系生态：

1. **太和主殿（核心主殿，全场体量最大）**：
   - 位于中轴线核心位置（`cx = 0, cz = -18`）。
   - **屋顶形制**：最高等级的重檐庑殿金顶（五脊四坡），四角起翘飞檐（飞檐翼角），正脊安设双向鸱吻吞脊兽，垂脊列装仙人走兽。
   - **大木作构架**：重檐双层斗拱出跳，红漆金柱回廊，隔扇门金钉朱门，棂花窗透光，高悬黑漆金字御匾。
   - **台基与御道**：三层汉白玉须弥座高台，四周环绕汉白玉望柱栏杆，正中设有九龙浮雕青金石御道丹陛石与文武两班步阶。

2. **东配殿 & 西配殿（东西两侧对称）**：
   - 对称分布于主殿前庭两侧（`cx = ±28, cz = -10`）。
   - **屋顶形制**：单檐歇山顶（九脊殿），覆盖碧绿琉璃瓦，与主殿金顶形成主从尊卑的古典色彩呼应。
   - 设檐下回廊、红柱格扇门窗与出挑斗拱。

3. **山门（场地前端前入口）**：
   - 位于场地最前端（`cx = 0, cz = 40`），为整个建筑群的起始序幕。
   - **三门并峙**：中央御门石券拱门洞高大，两侧设配门，朱红厚墙与金钉大门。
   - 门前设有全宽汉白玉石阶与一对威严镇门花岗石狮。

4. **千佛体素宝塔（五级浮屠古塔）**：
   - 矗立于庭院西北开阔花园高台（`cx = -34, cz = -32`），高达 42 个体素高度。
   - 五层逐级收分，各层均有出檐平座、飞檐悬铃与佛龛拱券，顶端耸立鎏金相轮与摩尼宝珠刹顶。

5. **晨钟暮鼓（钟楼与鼓楼）**：
   - 钟楼（东：`cx = 26, cz = 18`）与鼓楼（西：`cx = -26, cz = 18`）东西对峙。
   - 重檐四角攒尖宝顶阁楼，下层为券门青砖高台，上层为敞轩木构；钟楼内悬挂体素青铜古钟，鼓楼内安置朱红仪仗神鼓。

6. **中轴动线、水系与庭院生态**：
   - **中轴御道**：山门 → 汉白玉金水桥 → 庭院广场 → 青铜巨香炉 → 御道丹陛 → 太和主殿。
   - **金水河与金水桥**：单孔拱形汉白玉桥横跨金水池，池内点缀浮萍、翠绿荷叶与粉嫩荷花。
   - **青铜香炉（宝鼎）**：主殿前庭中轴安放双耳三足大香炉，内置炭火微光，缕缕青烟动态袅袅升空。
   - **古木参天**：曲干盘结的苍翠迎客古松与千年金秋银杏，落英缤纷。
   - **宫墙与漏窗**：全封闭朱红高墙，墙顶青灰筒瓦压檐，嵌有黑底金格古典漏窗。

## ⚡ 技术特性与性能保证

- **百万级逻辑体素，稳定 60~160+ FPS**：
  - 基于 `THREE.InstancedMesh` 批渲染架构，同类材质（实体、发光宫灯、鎏金相轮、半透明池水、植被）全场景合并为独立实例批次。
  - **总 DrawCalls ≤ 8**，旋转缩放极其流畅，无论核显还是独显均能稳定高帧率运行。
- **内置内部遮挡剔除算法 (Voxel Occlusion Culling)**：
  - 在几何编译期自动剔除所有 6 面全封闭的内部体素，降低 50% 以上几何负载与显存占用。
- **全动态光影与高品质软阴影**：
  - DirectionalLight 搭配 `2048x2048` 高分辨率 PCFSoftShadowMap 软阴影，精准投影檐角、斗拱、石狮与树木长影。
- **四时天象气象切换**：
  - **晌午·紫禁晴日**：蔚蓝晴空，高悬艳阳，金碧辉煌。
  - **落霞·孤鹜秋水**：橙红晚霞，斜阳长影，暮霭苍茫。
  - **月夜·华灯初上**：黛蓝深宵，皓月当空，百盏宫灯与流萤同辉。
  - **晨曦·紫气东来**：柔粉朝霞，薄雾初开，古刹钟鸣。
- **纯原生 Web Audio 禅意古韶乐**：
  - 零依赖外置音频文件，利用浏览器纯 Web Audio API 算法合成古刹编钟、铜磬泛音与五声音阶（宫商角徵羽），清幽悠扬。
- **获奖级新中式国潮玻璃拟态 UI**：
  - 宣纸米白与朱砂色调、毛玻璃拟态面板、名胜巡礼导览按钮、实时建筑形制典籍卡片。

## 🚀 运行方式

### 方式 1：双击一键运行（推荐，最简便）
直接在桌面 `zcode` 文件夹中双击：
- **`双击启动.bat`**：自动启动本地 Vite 开发服务器并调起浏览器打开 `http://localhost:5188`。

### 方式 2：命令行开发模式
在终端进入项目根目录：
```bash
# 1. 安装依赖（已预先安装完成）
npm install

# 2. 启动开发服务器
npm run dev
```
打开浏览器访问控制台提示的地址（默认：`http://localhost:5188`）。

### 方式 3：生产构建与静态预览
```bash
# 编译打包生产资源
npm run build

# 本地预览打包产物
npm run preview
```
